Governed Space

Integrity Criteria

Canonical Definition

Integrity Criteria Module (ICRM) defines the canonical criteria that a
governed entity must satisfy to be recognized as maintaining integrity. It
establishes the formal conditions against which integrity can be consistently
evaluated, measured, and independently verified throughout the entity's
complete lifecycle.

Module Purpose

ICRM transforms the definition of integrity into explicit evaluation criteria.
It specifies the characteristics, properties, and requirements that determine
whether integrity is present, maintained, degraded, or absent.

Without defined criteria, integrity remains subjective and cannot be governed
consistently.

Operational Role

ICRM provides the objective reference criteria used by all subsequent
integrity governance processes, ensuring that integrity assessments are based
on predefined and transparent standards rather than individual interpretation.

Operational Space

ICRM governs:

  • integrity criteria
  • evaluation requirements
  • qualification conditions
  • consistency requirements
  • integrity qualification rules.


Minimum Implementation Framework

An implementation of ICRM should define:

  • integrity criteria
  • mandatory requirements
  • optional requirements
  • evaluation logic
  • acceptance conditions.


Example Use Cases

Use Case 1 — AI Governance

Define the criteria that an autonomous AI system must satisfy to maintain
behavioral and operational integrity.

Use Case 2 — Document Integrity

Establish the criteria required for a document to be considered complete,
authentic, accurate, and unaltered throughout its lifecycle.

Canonical Closing Statement

Integrity can only be evaluated against clearly governed criteria. Integrity
Criteria Module establishes the objective conditions that transform the
concept of integrity into a measurable, governable, and independently
verifiable reference for every governed entity.
