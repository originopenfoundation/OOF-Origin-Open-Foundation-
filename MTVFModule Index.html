Module Registry

MTVF® modules define the operational validation mechanisms
used within the Multi-Layer Truth Validation Framework.

Each module performs a distinct structural role
inside the validation process.

Together, the modules create a complete integrity control cycle
for high-risk decision environments.

CLIE — Cross-Layer Integrity Engine

Category: AI Interpretation
Type: Supervisory Integrity Module

CLIE supervises interaction between validation layers
and detects structural inconsistencies, bias propagation,
and cross-layer conflicts.

ISCI — Integrity State Classification Index

Category: AI Interpretation
Type: Integrity Classification Module

ISCI classifies the integrity state of a decision
after cross-layer validation and translates validation outcomes
into measurable structural levels.

SCP — Structural Contamination Protocol

Category: AI Interpretation
Type: Containment and Safeguard Module

SCP isolates, contains, and revalidates decision processes
when validation integrity becomes structurally compromised.

AAIM — AI Agent Integrity Module

Category: AI Interpretation
Type: Integrity and Validation Module

AAIM applies MTVF validation logic to autonomous
and multi-agent environments, ensuring that agent behavior
remains traceable, validated, and contextually consistent.

Structural Role of the Module System

Within MTVF®, the module system operates as a complete
decision integrity control structure:

  • CLIE detects structural inconsistency
  • ISCI classifies integrity state
  • SCP contains structural contamination
  • AAIM extends validation into agent execution environments

Together, these modules ensure that validation remains
operational, auditable, and enforceable.
