Canonical Definition

Origin Declaration Standard (ODS™) defines how the origin of digital content
is declared in a clear, simple, and unambiguous way.

ODS™ does not evaluate content.
ODS™ defines declared origin.

Purpose

The purpose of ODS™ is to:

  • establish a simple declaration system
  • distinguish human and AI-generated content
  • enable monetization only where origin is declared
  • ensure accountability of content creation

Core Principle

Content without declared origin has no monetization eligibility.

Origin States (Canonical)

Only three origin states are defined:

  • HGC — Human Generated Content
  • AGC — AI Generated Content
  • UGC — Unknown Generated Content

No additional origin states are permitted.

Declaration Rule

  • origin declaration is voluntary
  • declaration must be explicit
  • absence of declaration results in UGC status

Dominant Origin Rule

The declared origin must reflect the dominant generation process
of the visual content.

This rule applies to the primary visual layer only.

Editing, enhancement, post-production, or supporting processes
do not change the declared origin.

Scope Clarification

ODS™ evaluates what is seen, not how it was technically processed.

The following do not affect origin classification:

  • editing
  • color correction
  • sound design
  • compression
  • technical enhancement
  • non-generative AI assistance

Only the core visual generation determines origin.

Monetization Rule

Monetization is allowed only when:

  • origin is declared
  • responsibility (creator or entity) is defined

Non-Declared Content

If origin is not declared:

  • content is classified as UGC
  • monetization is not permitted

No Owner / No Origin

Content without:

  • declared origin
  • responsible entity

cannot be monetized.

Responsibility Rule

  • the declaring entity is responsible for the declared origin
  • misdeclaration transfers responsibility to the declarer
  • ODS™ remains neutral

Scope

ODS™ applies to:

  • video
  • audio
  • podcasts
  • digital media content

Methodology

  • identify content origin
  • declare origin (HGC / AGC / UGC)
  • assign responsibility (creator / entity)
  • enable or restrict monetization

Output

Declared content state:

  • origin defined
  • responsibility assigned
  • monetization eligibility determined

Structural Principle

Without origin, there is no ownership.
Without ownership, there is no monetization.

Structural Limitation

ODS™ intentionally defines only three origin states.

Complex or ambiguous cases are resolved through:

  • the dominant origin rule
  • or default classification as UGC

Canonical Closing Statement

Content creation is free.
Monetization requires declaration.
