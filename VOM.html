VOM™ — Video Origin Module

OOF™ Origin Open Foundation™

Independent Methodological Authority

Category: AI and Interpretation
Subcategory: Content Origin Declaration
Module: Video Origin Module (VOM™)
Type: Declaration Module
Standard: Origin Declaration Standard (ODS™)
Status: Canonical Module
Version: 1.0
Effective Date: 17 March 2026


Canonical Definition

The Video Origin Module (VOM™) defines how the origin of video content
is declared using a single, visible origin code.

The module enables immediate recognition of whether video content
is human generated, AI generated, or undeclared.

Declaration

Only one origin code may be used:

  • HGC — Human Generated Content
  • AGC — AI Generated Content
  • UGC — Unknown Generated Content

Usage

Video Level (required — single code)

One origin code must be visibly present on the video.

Examples:

  • HGC
  • AGC
  • UGC

Description Level (required)

The declaration must be included in the description: 

Origin: HGC
OOF Compatible — ODS™ Standard
https://originopenfoundation.org

OOF Compatibility

Content using this module may include the statement:

OOF Compatible — ODS™ Standard

A reference link to the official source is required.

Use Case 1 — Platform Monetization Clarity

Scenario

A platform hosts both human and AI-generated video content.

Application

Creators declare origin using a single code (HGC / AGC / UGC).

Result

  • Clear monetization eligibility
  • Reduced ambiguity
  • Improved platform trust

Use Case 2 — Creator Transparency

Scenario

A creator publishes video content to a global audience.

Application

The creator declares origin directly on the video and in the description.

Result

  • Immediate viewer clarity
  • Increased trust
  • Clear ownership signal

Structural Principle

One code defines origin.
Declared origin defines value.

Closing Statement

Clarity does not require complexity.
It requires declaration.
