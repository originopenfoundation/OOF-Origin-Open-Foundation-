# Security Policy

OOF maintains public access to its methodological resources while protecting the supporting delivery and application infrastructure.

## Reporting a vulnerability

Please report suspected vulnerabilities to [contact@originopenfoundation.org](mailto:contact@originopenfoundation.org). Include the affected URL or component, a concise reproduction, impact, and any relevant evidence. Do not publish credentials, personal data, or exploit instructions in a public issue.

## Scope

The public static site, repository automation, and the LaRA service are in scope. Public methodology pages are intentionally available to visitors, search engines, and authorized AI retrieval systems. Availability controls must not rely solely on a crawler user-agent or a visitor's country.

## Supported configuration

The active `main1` branch is the maintained website source. Production infrastructure settings, including edge DDoS controls, GitHub organization controls, and Render service settings, are operated separately from this repository and must be changed by an authorized administrator.

## Disclosure handling

Reports are assessed privately. OOF may request clarification, coordinate a remediation window, and publish a concise remediation note after a fix is available. Reports that contain personal data or credentials are handled only as necessary to investigate and remediate the issue.
